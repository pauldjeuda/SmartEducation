# SmartEducation (SMED)

Site institutionnel bilingue et installable (PWA) de SmartEducation, réalisé avec Next.js, TypeScript et Tailwind CSS.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir `http://localhost:3000/fr`. Les pages françaises sont sous `/fr`; leur version anglaise est sous `/en`.

## Commandes

- `npm run dev` : développement
- `npm run build` : compilation de production
- `npm run start` : serveur de production
- `npm run lint` : analyse ESLint

## Images

Les photos éditoriales locales sont issues de Pexels. Elles sont utilisées sous la licence Pexels, qui autorise l’utilisation gratuite sur un site web. Les photographes sont crédités dans le pied de page et dans `content/image-credits.md`.

Le logo fourni par SmartEducation est conservé comme source de marque. Les photos sont des illustrations éditoriales et ne prétendent pas représenter des bénéficiaires ou des projets réels de l’association.
